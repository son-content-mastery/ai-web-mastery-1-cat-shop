# Accessibility and performance

The site targets practical WCAG 2.2 AA through skip navigation, native controls, labeled landmarks, visible focus, programmatic open/selected states, keyboard gallery controls, 44px targets, non-color-only messages, Thai line height, and reduced motion. Local Stitch images have fixed dimensions and below-fold lazy loading; six local SVG paths replace an icon font. Static Astro avoids client hydration and third-party carousel/animation libraries. Google Fonts remain the only external visual dependency; self-host if licensing and font files become available.
