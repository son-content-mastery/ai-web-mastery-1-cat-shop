# Architecture

Astro generates static HTML. `BaseLayout` owns metadata, JSON-LD injection, and landmarks; header/footer, cards, breadcrumb, icons, and gallery are shared Astro components. Product and blog records live as typed Markdown entries in `src/content/`; `src/lib/catalog.ts` maps them to the shared view model, while business/channel configuration remains in `src/config/site.ts`. `src/lib/structured-data.ts` creates server-rendered category `CollectionPage`/`ItemList`/`BreadcrumbList` graphs and product `Product`/`BreadcrumbList` graphs. Product `Offer` data is emitted only when a numeric visible price exists; availability and reviews are never inferred. Dynamic Astro routes pre-render product, brand, category, and article pages. Tailwind contains normalized Stitch tokens; global CSS holds type loading, focus, motion, and a few cross-component utilities. JavaScript is isolated to menu, filters, gallery, and clipboard behavior.

Keystatic is a local authoring tool mounted at `/keystatic/` only during `npm run dev`. Its React and Markdoc integrations support the editor and do not hydrate the public site. Production builds omit the editor routes and remain static, with no backend, database, account, inventory state, or deployed CMS service.
